# Setup Guide

> **Windows Users**: We recommend using [Docker Setup](DOCKER_SETUP.md) - it's much easier and avoids PostgreSQL installation issues.

## Prerequisites

- **Node.js** 18+ and npm
- **PostgreSQL** 14+ (with psql CLI tools)
- **Python** 3.9+ (for model server)

## Quick Start (All Platforms)

### 1. Clone and Install Dependencies

```bash
git clone <your-repo-url>
cd Restaurant-Discounts
npm install
cd apps/web
npm install
```

### 2. Install PostgreSQL

#### Windows
- Download from [postgresql.org](https://www.postgresql.org/download/windows/)
- **Important**: During installation, make sure "Command Line Tools" is selected
- Add PostgreSQL's `bin` folder to your PATH (usually `C:\Program Files\PostgreSQL\16\bin`)
- Verify: `psql --version`

#### macOS
```bash
brew install postgresql@16
brew services start postgresql@16
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
```

### 3. Setup Database

The cross-platform Node.js script works on Windows, macOS, and Linux:

```bash
cd apps/web
npm run db:setup
```

**Custom configuration:**
```bash
# Using environment variables
DB_USER=myuser DB_PASSWORD=mypass DB_NAME=mydb npm run db:setup

# Or pass as arguments
node scripts/setup-db.mjs mydb myuser mypass
```

**Windows users**: If you get a permission error, set your PostgreSQL superuser password:
```cmd
set PGPASSWORD=your_postgres_password
npm run db:setup
```

### 4. Run Migrations and Seed Data

```bash
npm run db:migrate
npm run db:seed
```

### 5. Setup Model Server (Python)

```bash
cd ../../services/model-server

# Windows
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 6. Configure Environment

Create `apps/web/.env` (if not auto-created):

```bash
# Database (auto-generated by db:setup)
DATABASE_URL="postgresql://restaurant_user:restaurant_pass@localhost:5432/restaurant_discounts?schema=public"

# Model Server
MODEL_SERVER_URL="http://localhost:8000"

# Optional
CRON_SECRET="your-secret-key"
```

### 7. Start Development Servers

**Option A - Run all services together:**
```bash
cd apps/web
npm run dev:all
```

**Option B - Run separately:**

Terminal 1 (Next.js):
```bash
cd apps/web
npm run dev
```

Terminal 2 (Python Model Server):
```bash
cd services/model-server
# Windows: venv\Scripts\activate
# macOS/Linux: source venv/bin/activate
uvicorn app:app --reload --port 8000
```

### 8. Access the App

- Frontend: http://localhost:3000
- Model Server API: http://localhost:8000/docs

## Troubleshooting

### Windows: "psql is not recognized"
1. Find your PostgreSQL installation (usually `C:\Program Files\PostgreSQL\16`)
2. Add `C:\Program Files\PostgreSQL\16\bin` to your System PATH
3. Restart your terminal/IDE

### Database Setup Fails (Authentication Error)

**Test your connection first:**
```cmd
psql -U postgres -c "SELECT 1;"
```

If this prompts for a password or fails, you need to set PGPASSWORD:

**Windows (Command Prompt):**
```cmd
set PGPASSWORD=your_postgres_password
npm run db:setup
```

**Windows (PowerShell):**
```powershell
$env:PGPASSWORD="your_postgres_password"
npm run db:setup
```

**Mac/Linux:**
```bash
export PGPASSWORD=your_postgres_password
npm run db:setup
```

**If you forgot your postgres password:**

Windows - Reset via pg_hba.conf:
1. Open "Services" → Find "postgresql-x64-16" → Stop service
2. Edit `C:\Program Files\PostgreSQL\16\data\pg_hba.conf`
3. Find this line:
   ```
   host    all             all             127.0.0.1/32            md5
   ```
   Change `md5` to `trust`
4. Restart PostgreSQL service
5. Run: `psql -U postgres -c "ALTER USER postgres PASSWORD 'newpassword';"`
6. Change `trust` back to `md5` in pg_hba.conf
7. Restart service again
8. Set: `set PGPASSWORD=newpassword` and retry setup

### Database Connection Errors
- Check PostgreSQL is running: `psql -U postgres -c "SELECT version();"`
- Verify DATABASE_URL in `.env` matches your credentials
- Windows: Use `127.0.0.1` instead of `localhost` if connection fails

### Python Module Errors
- Make sure virtual environment is activated (you should see `(venv)` in your terminal)
- Re-run: `pip install -r requirements.txt`

## Scripts Reference

| Command | Description |
|---------|-------------|
| `npm run db:setup` | Create database, user, and configure .env |
| `npm run db:migrate` | Apply Prisma migrations |
| `npm run db:seed` | Seed database with sample data |
| `npm run db:reset` | Reset database (caution: deletes all data) |
| `npm run dev` | Start Next.js dev server only |
| `npm run dev:all` | Start Next.js + Python model server |
